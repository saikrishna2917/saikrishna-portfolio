# Sai Krishna Mateti | Backend Engineer Portfolio

A highly professional, dark-themed developer portfolio built with React and Vite. It features a "system-health" visual aesthetic, custom floating and typing animations, scroll-spy navigation, and an interactive timeline for professional experience.

## 🚀 Getting Started

Follow these steps to run the portfolio locally on your machine.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository** (if you haven't already):
   ```bash
   git clone https://github.com/saikrishna2917/saikrishna-portfolio.git
   cd saikrishna-portfolio
   ```

2. **Install the dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **View the application**:
   Open your browser and navigate to `http://localhost:5173` (or the local URL provided in your terminal).

## 🛠️ Tech Stack
- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (CSS Variables, Flexbox, CSS Grid)
- **Icons**: Lucide React
- **Animations**: Custom CSS Keyframes & React Intersection Observer

## 📦 Building for Production

When you are ready to deploy the site (to Vercel, Netlify, GitHub Pages, etc.), run:

```bash
npm run build
```
This will generate an optimized, production-ready bundle in the `dist` folder.

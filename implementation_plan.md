## Proposed UI Styling Architecture

### 1. The Canvas
- **Background**: A very soft, cool off-white (`#F8FAFC`). This ensures that pure white cards pop off the page.
- **Cards**: Pure white (`#FFFFFF`) with a very soft, large drop shadow (`box-shadow: 0 20px 40px -15px rgba(0,0,0,0.05)`) and smooth rounded corners (`border-radius: 24px`).
- **Accent Color**: A vibrant, modern royal blue (`#2563EB`) or primary cyan to draw the eye to important buttons and links, keeping the rest of the palette strictly neutral.

### 2. Typography
- **Headings**: `Inter`, extremely bold (`font-weight: 800`), dark slate color (`#0F172A`), with slightly tight letter spacing for a modern tech feel.
- **Body**: Soft gray (`#475569`), highly legible, with generous line height (`1.7`).

### 3. Component Details
- **Hero**: Massive text introduction. Clean pill-shaped buttons with subtle hover lift effects. No images.
- **Tech Stack**: A beautiful grid of floating white cards. Each card will have a subtle icon and clear, spaced-out text.
- **Projects & Experience**: Displayed inside large, elegant white panels. Instead of images, we will use clean list layouts with blue checkmarks for features, making it look like a high-end SaaS product dashboard.
